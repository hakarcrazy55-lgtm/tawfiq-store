# 🏪 محلات توفيق محمد — النظام المحاسبي

نظام محاسبي متكامل لمحلات توفيق محمد لبيع قطع غيار الدراجات النارية وأدوات الطاقة الشمسية.

## المميزات
- 📊 لوحة تحكم شاملة
- 🛒 فواتير مبيعات متعددة الأصناف
- 📦 فواتير مشتريات متعددة الأصناف
- 🗄️ إدارة المخزون
- 💸 إدارة المصروفات
- 👥 إدارة العملاء والموردين
- 🏦 صناديق القبض والصرف
- 📈 تقارير مالية
- 🖨️ طباعة فواتير احترافية

## الاستخدام
افتح الرابط مباشرة في المتصفح من أي جهاز.

> **ملاحظة:** البيانات تُحفظ في المتصفح (localStorage) — كل جهاز له بياناته الخاصة.
> للمشاركة استخدم زر "تصدير نسخة احتياطية" ثم "استيراد" في الجهاز الآخر.
